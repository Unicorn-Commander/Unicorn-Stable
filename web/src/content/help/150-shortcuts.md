`Cmd` on a Mac, `Ctrl` everywhere else.

| Chord | Does |
|---|---|
| `Cmd/Ctrl K` | Quick switcher — jump to a channel, person, agent or server |
| `Cmd/Ctrl ⇧ F` | Search messages across all channels |
| `Cmd/Ctrl /` | Shortcuts cheatsheet |
| `Cmd/Ctrl ↑` | Edit your last message |
| `Alt ↑` / `Alt ↓` | Move through the sidebar |
| `↑` / `↓` | Move through mention, emoji and slash suggestions |
| `Enter` | Send |
| `Shift Enter` | Newline |
| `Esc` | Close a dialog, or cancel an edit |

The same list is always one `Cmd/Ctrl /` away without opening Help.
