The sidebar has three sections, each of which collapses independently and
remembers that it is collapsed:

- **Channels**
- **People** — your direct messages, grouped by who they are with
- **Groups** — private multi-party rooms

## Folders

You can file channels into folders. A folder belongs to one server, so the same
folder name on two servers is two different folders — which is what you want
when `#general` exists in both places.

People rows can be filed too. A person is identified by name, which is why
people folders are kept per-server rather than globally.

## Collapse

Every section and every folder collapses. Collapse state persists, so a sidebar
you tidied stays tidy across reloads.

## Filter

Type in the sidebar's filter box to narrow what is on screen. This is a live
filter of the sidebar itself, not a message search — for message search see
[Find things](help:search).

## Keyboard

`Alt ↑` / `Alt ↓` walk the sidebar. They walk **exactly what you can see** —
the same model the sidebar renders, with your filter and collapse state applied.
If a row is hidden, the keyboard skips it too.
