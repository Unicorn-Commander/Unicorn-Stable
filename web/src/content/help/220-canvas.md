Canvas is the right-hand drawer where a piece of work lives, instead of
scrolling away up the channel.

Open it from the **Canvas** toggle in the room header. The toggle carries a dot
when the room has an artifact — and a distinct marker when one arrived while
the drawer was closed, so "something new happened" reads differently from
"there is stuff in here".

## What a canvas can hold

Markdown · Code · HTML · SVG · Mermaid diagrams · React components · Sheets.

Rendered ones (HTML, SVG, Mermaid, React) have a preview and a source view.

## Versions

Every change is a version. You can:

- step back and forward through the **history**
- **diff** two versions to see exactly what changed
- **revert** to an earlier one

## Who edits it

Both of you. An agent can create and revise a canvas as part of answering, and
you can edit it directly in the drawer. Edits made in the drawer are a
whole-buffer rewrite and land as a new version like any other.
