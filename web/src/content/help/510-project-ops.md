**Promote to Project Ops task** on a message opens a small form: pick the
project, adjust the title, set a priority (Low / Medium / High / Urgent), and
create it.

The message stays where it is; you get a task that points back at it.

If the project list comes back empty, your server has Project Ops configured
but your account cannot see any projects — that is a Project Ops permission
question, not a Stable one.
